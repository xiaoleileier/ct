## 系统要求

### 硬件要求
- **CPU**: 至少 2 核心（推荐 4 核心）
- **内存**: 至少 4GB（推荐 8GB+）
- **硬盘**: 至少 20GB 可用空间

### 操作系统
- Ubuntu 20.04 / 22.04 LTS（推荐）
- macOS 11+ (开发环境)
- CentOS 8+ / RHEL 8+
- Windows 10/11 + WSL2

### 软件版本要求
| 软件 | 版本要求 | 说明 |
|------|----------|------|
| Ruby | 3.2.x | 核心运行环境 |
| Node.js | 20.x | 前端构建工具 |
| PostgreSQL | 12+ | 数据库 |
| Redis | 6+ | 缓存和队列 |
| pnpm | 8.x+ | 包管理器 |

## 环境准备

### Ubuntu/Debian 系统

#### 1. 更新系统
```bash
sudo apt update && sudo apt upgrade -y
```

#### 2. 安装基础依赖
```bash
sudo apt install -y \
  curl wget git build-essential \
  libssl-dev libreadline-dev \
  zlib1g-dev libpq-dev \
  imagemagick libvips42 \
  shared-mime-info
```

#### 3. 安装 PostgreSQL
```bash
# 安装 PostgreSQL 14
sudo apt install -y postgresql postgresql-contrib

# 启动服务
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 创建数据库用户
sudo -u postgres createuser -s chatwoot
sudo -u postgres psql -c "ALTER USER chatwoot WITH PASSWORD 'your_password';"
```

#### 4. 安装 Redis
```bash
# 安装 Redis
sudo apt install -y redis-server

# 启动服务
sudo systemctl start redis-server
sudo systemctl enable redis-server

# 验证安装
redis-cli ping  # 应返回 PONG
```

#### 5. 安装 Ruby (使用 rbenv)
```bash
# 安装 rbenv
git clone https://github.com/rbenv/rbenv.git ~/.rbenv
echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init -)"' >> ~/.bashrc
source ~/.bashrc

# 安装 ruby-build
git clone https://github.com/rbenv/ruby-build.git ~/.rbenv/plugins/ruby-build

# 安装 Ruby 3.2.2
rbenv install 3.2.2
rbenv global 3.2.2

# 验证安装
ruby -v  # 应显示 ruby 3.2.2
```

#### 6. 安装 Node.js (使用 nvm)
```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc

# 安装 Node.js 20
nvm install 20
nvm use 20
nvm alias default 20

# 验证安装
node -v  # 应显示 v20.x.x
npm -v
```

#### 7. 安装 pnpm
```bash
npm install -g pnpm@latest

# 验证安装
pnpm -v  # 应显示 8.x 或更高版本
```

### 4. 使用 Systemd 管理服务

#### 创建 Web 服务
```bash
sudo nano /etc/systemd/system/chatwoot-web.service
```

```ini
[Unit]
Description=Chatwoot Web Service
After=network.target postgresql.service redis.service

[Service]
Type=simple
User=chatwoot
WorkingDirectory=/home/chatwoot/chatwoot
Environment="RAILS_ENV=production"
Environment="NODE_ENV=production"
EnvironmentFile=/home/chatwoot/chatwoot/.env.production
ExecStart=/home/chatwoot/.rbenv/shims/bundle exec puma -C config/puma.rb
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

#### 创建 Worker 服务
```bash
sudo nano /etc/systemd/system/chatwoot-worker.service
```

```ini
[Unit]
Description=Chatwoot Sidekiq Worker
After=network.target postgresql.service redis.service

[Service]
Type=simple
User=chatwoot
WorkingDirectory=/home/chatwoot/chatwoot
Environment="RAILS_ENV=production"
EnvironmentFile=/home/chatwoot/chatwoot/.env.production
ExecStart=/home/chatwoot/.rbenv/shims/bundle exec sidekiq -C config/sidekiq.yml

RestartSec=10

[Install]
WantedBy=multi-user.target
```

#### 启动服务
```bash

# 启动服务

sudo systemctl start chatwoot-worker

# 设置开机自启
sudo systemctl enable chatwoot-web

# 查看状态

sudo systemctl status chatwoot-worker
```

### 5. 配置 Nginx

```bash
sudo nano /etc/nginx/sites-available/chatwoot
```

```nginx
upstream chatwoot_server {
  server 127.0.0.1:3000 fail_timeout=0;
}

server {
  listen 80;
  server_name chat.yourdomain.com;
  
  # 重定向到 HTTPS
  return 301 https://$server_name$request_uri;
}

server {
  listen 443 ssl http2;
  server_name chat.yourdomain.com;

  # SSL 证书配置
  ssl_certificate /etc/letsencrypt/live/chat.yourdomain.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/chat.yourdomain.com/privkey.pem;

  # SSL 优化
  ssl_protocols TLSv1.2 TLSv1.3;
  ssl_ciphers HIGH:!aNULL:!MD5;
  ssl_prefer_server_ciphers on;

  # 日志
  access_log /var/log/nginx/chatwoot_access.log;
  error_log /var/log/nginx/chatwoot_error.log;

  # 上传大小限制
  client_max_body_size 50M;

  # 根目录
  root /home/chatwoot/chatwoot/public;

  location / {
    try_files $uri @chatwoot;
  }

  location @chatwoot {
    proxy_pass http://chatwoot_server;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
  }

  # WebSocket 支持
  location /cable {
    proxy_pass http://chatwoot_server/cable;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header Host $http_host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-Proto https;
    proxy_redirect off;
  }
}
```

启用配置：
```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/chatwoot /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

## 常见问题排查

### 问题 1: 无法启动 Rails 服务器

**症状：**
```
Address already in use - bind(2) (Errno::EADDRINUSE)
```

**解决方案：**
```bash
# 查找占用端口的进程
lsof -i :3000

# 杀死进程
kill -9 <PID>

# 或使用其他端口
bundle exec rails server -p 3001
```

---

### 问题 2: 数据库连接失败

**症状：**
```
PG::ConnectionBad: could not connect to server
```

**解决方案：**
```bash
# 检查 PostgreSQL 状态
sudo systemctl status postgresql

# 检查连接配置
psql -h localhost -U chatwoot -d chatwoot_development

# 重置数据库密码
sudo -u postgres psql
ALTER USER chatwoot WITH PASSWORD 'new_password';
\q

# 更新 .env 文件中的密码
```

---

### 问题 3: Redis 连接失败

**症状：**
```
Error connecting to Redis on localhost:6379
```

**解决方案：**
```bash
# 检查 Redis 状态
sudo systemctl status redis-server

# 启动 Redis
sudo systemctl start redis-server

# 测试连接
redis-cli ping

# 检查 Redis 配置
cat /etc/redis/redis.conf | grep bind
```

---

### 问题 4: 前端编译失败

**症状：**
```
ERROR in ... Module not found
```

**解决方案：**
```bash
# 清除缓存和依赖
rm -rf node_modules pnpm-lock.yaml
rm -rf tmp/cache

# 重新安装依赖
pnpm install

# 清除 Rails 缓存
bundle exec rails tmp:clear

# 重新编译
pnpm dev
```

---

## 备份和恢复

### 数据库备份
```bash
# 创建备份脚本
nano ~/backup-chatwoot.sh

#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backup/chatwoot"
mkdir -p $BACKUP_DIR

# 备份数据库
pg_dump -h localhost -U chatwoot chatwoot_production > $BACKUP_DIR/db_$DATE.sql

# 备份文件
tar -czf $BACKUP_DIR/storage_$DATE.tar.gz /home/chatwoot/chatwoot/storage

# 删除 30 天前的备份
find $BACKUP_DIR -type f -mtime +30 -delete

# 添加执行权限
chmod +x ~/backup-chatwoot.sh

# 添加定时任务（每天凌晨 2 点）
crontab -e
0 2 * * * /home/chatwoot/backup-chatwoot.sh
```

### 数据库恢复
```bash
# 恢复数据库
psql -h localhost -U chatwoot chatwoot_production < backup.sql

# 恢复文件
tar -xzf storage_backup.tar.gz -C /
```
